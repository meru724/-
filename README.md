# Type Garden

毎日、少しずつ練習できるタイピングアプリです。日本語ローマ字・英単語、30 / 60 / 120 秒の練習に対応しています。

## Windows で使う（コマンド入力不要）

配布用の `typegarden-windows.zip` をダウンロードした場合：

1. エクスプローラーで「ダウンロード」フォルダーを開きます。
2. `typegarden-windows.zip` を右クリックし、「すべて展開」を選びます。
3. 展開したフォルダーの `typegarden.html` をダブルクリックします。
4. Microsoft Edge または Google Chrome で練習画面が開きます。入力欄をクリックし、キーボードを半角英数にして練習してください。

インストールやコマンド入力は不要です。次回も同じ `typegarden.html` を開くだけです。ファイルは同じ場所に保管してください。ブラウザやファイルの保存場所を変えると、以前のきろくが表示されない場合があります。

## 開発用の起動

Node.js 18 以上が必要です。外部パッケージのインストールは不要です。

```sh
cd /workspace/-
npm start
```

ポート 3000 で起動します。`PORT=8080 npm start` で変更できます。HTML / CSS / JavaScript のみで構成されているため、任意の静的ファイルサーバーでも配信できます。

`npm run build` で、直接ブラウザで開ける単一ファイル版 `dist/typegarden.html` を生成できます。こちらはサーバーの起動が不要です。

## Web公開

`npm run build` は Web 配信用の `dist/index.html` も生成します。外部の API、データベース、秘密情報は不要です。

GitHub Pages 用の自動公開設定を `.github/workflows/pages.yml` に用意しています。リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** に設定すると、`main` への push 時にテスト・ビルド・公開を行います。手動で実行する場合は Actions → Publish Type Garden → Run workflow を使います。利用中の GitHub プランで Pages が利用可能である必要があります。リポジトリの公開・非公開設定は自動変更しません。

公開の完了と実際の URL は、Actions の deploy 結果と Pages の設定画面で確認します。設定ファイルを用意しただけでは、Web 公開は完了しません。

## 使い方

- モードと練習時間を選び、入力欄に最初の文字を入力すると計測開始。
- 表示されたローマ字 / 英単語を入力して、スペースで次のことばへ。日本語入力（IME）はオフにしてください。ローマ字は画面に表示されるつづりに合わせます。
- 間違えた文字は Backspace で修正。Esc または「やり直す」でリセット。
- 制限時間が終わると成績を表示し、最新 50 回のきろくをブラウザの localStorage に保存。モードと時間の組み合わせごとにベストを表示します。
- 途中でモード・時間を変えたり、きろく画面へ移動すると、進行中の練習はリセットされます。未完了の練習は保存しません。

WPM は正しく入力した文字数（完了した単語の区切りスペースを含む）÷ 5 ÷ 経過分数。正確率は正しい文字の入力回数 ÷ 全文字の入力回数で、修正前のミスも含みます。バックスペースと区切り操作は正確率の集計対象外です。きろくはこのブラウザ内の保存で、端末間の同期はありません。保存不可でも練習自体は利用できます。

## 検証

```sh
npm test
```

Node.js 標準テストランナーで、制限時間、採点、修正入力、課題生成、保存データの検証を行います。

Playwright for Python と Chromium が利用可能な環境では、サーバー起動後に `python tests/browser_smoke.py` で画面の操作テストも実行できます。`CHROMIUM_PATH` でブラウザの実行ファイル、`TYPEGARDEN_URL` で検証対象を指定できます。テストは独立したブラウザ内で入力・制限時間終了・きろくの保存と削除・スマートフォン表示・保存不可時の練習を確認します。
